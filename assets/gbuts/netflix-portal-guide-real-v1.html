실제 인증 페이지 화면

넷플릭스 인증코드, 직접 확인하세요

1:1 채팅으로 받은 전용 링크와 6자리 이메일 PIN을 준비해 주세요.

1채팅의 링크 열기

1:1 채팅으로 받은
이메일 인증 링크를 눌러 주세요.

2이메일 PIN 입력

채팅에서 받은 6자리 PIN을
입력하고 「확인」을 눌러 주세요.

이 PIN은 인증 페이지 입장용입니다.
넷플릭스 인증코드와는 달라요.

3필요한 인증코드 선택

넷플릭스에서 먼저 인증을 요청한 다음, 화면에 표시된 종류에 맞는 버튼을 눌러 주세요.

4자리 로그인 코드
로그인 화면에서 4자리를 요청한 경우

6자리 인증 코드
계정 또는 가구 인증 화면에서 요청한 경우
조회에는 최대 90초 정도 걸릴 수 있어요.
코드가 없거나 만료됐다면 넷플릭스에서 새 코드를 요청한 뒤 다시 확인해 주세요.

4넷플릭스 화면에 코드 입력

표시된 숫자 코드를 복사하거나 직접 입력하면 됩니다.
계속 확인되지 않으면 구매하신 1:1 채팅으로 문의해 주세요.

계정과 프로필은 그대로 유지해 주세요.
본인 전화번호 등록·추가 결제·계정 설정 변경은 하지 마세요.
화면은 실제 인증 페이지를 캡처한 것으로, 실제 PIN과 인증코드는 포함되지 않았습니다.
