실제 이메일 확인 페이지 화면

넷플릭스 이메일 인증, 이렇게 하세요

1:1 채팅으로 받은 이메일 링크와 6자리 이메일 PIN을 준비하세요.

1채팅의 이메일 링크 열기

왼쪽 화면이 나타나면
이메일 확인 페이지에
정상적으로 접속한 것입니다.

2이메일 PIN 입력

채팅에서 받은 6자리를 입력한 뒤
「확인」을 눌러주세요.

← 표시한 곳에 입력합니다.
이메일 PIN은 이메일함 입장용입니다.

3요청한 넷플릭스 메일 확인

오른쪽 위 새로고침

넷플릭스에서 인증을 요청하면 이 메일함에 새 메일이 표시됩니다.
아래는 실제 메일이 없는 상태의 화면입니다. 메일이 도착하면 가장 최근 메일을 열어주세요.

메일이 없으면 넷플릭스에서 인증을 다시 요청하고, 잠시 후 새로고침하세요.
이 화면에는 최근 10분 내 수신한 메일만 표시됩니다.

4넷플릭스에서 인증 완료

숫자 코드가 나오면 넷플릭스 화면에 입력하세요.
인증 링크가 나오면 해당 링크를 눌러 완료하세요.

계정과 프로필 설정은 그대로 유지해주세요.계정 이메일·비밀번호·프로필·결제 설정은 변경하지 마세요.
캡처 화면에는 실제 비밀번호·이메일 PIN·인증 코드가 포함되어 있지 않습니다.
